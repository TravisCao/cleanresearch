# Show research status

Read [PROJECT.md](../../../PROJECT.md), [hypotheses.md](../../../hypotheses.md), [experiments/INDEX.md](../../../experiments/INDEX.md), [insights.md](../../../insights.md), and [memory/decisions.md](../../../memory/decisions.md).

Return one screen with these items in this order:

1. The research question.
2. Each active hypothesis and its current state.
3. The last three experiments, newest first, with one-line verdicts.
4. The newest insight.
5. One suggested next step.

Name missing or uncertain information directly. Keep evidence links beside the statements they support. Suggest only one next step that follows from the current evidence.
