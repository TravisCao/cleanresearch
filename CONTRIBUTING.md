# Contributing to ResearchOS

Issues and pull requests are welcome.

- Describe the researcher’s problem in plain language.
- Field-specific skills are welcome. State the field, task, required inputs, expected files, and limits.
- Keep every sentence readable by a researcher who is not a programmer. Explain each necessary technical term in the same sentence.
- Test each changed skill with a real AI agent before you open a pull request. Include the agent name, the request you gave it, and what you checked.
- Keep changes focused. Do not add a tool or workflow unless the repository contains the instructions and files needed to use it.

By contributing, you agree that your contribution can be distributed under the repository’s [MIT License](LICENSE).
