# Maintainer checklist: record the cleanResearch demo
> For maintainers only. Record in a throwaway clone so the repository remains clean.
- [ ] Use a 1280 × 800 terminal with a 20–22 px monospace font.
- [ ] Hide notifications, personal paths, account names, and shell history.
- [ ] Start from a fresh clone with the shipped E001 example unchanged.
- [ ] Open the repository in the AI coding assistant used for the recording.
- [ ] Set the target length to 90 seconds; remove pauses longer than two seconds.
- [ ] Prompt 1: `Read AGENTS.md and show my research status.`
- [ ] Prompt 2: `What evidence supports H1, and how was each result produced?`
- [ ] Prompt 3: `Explain the E001 result and its limits in plain language.`
- [ ] Prompt 4: `Audit this project before I share the result.`
- [ ] Prompt 5: `What is the one best next step for this project?`
- [ ] Keep the assistant’s file paths and the E001 numbers visible long enough to read.
- [ ] Show `experiments/001-first-example/EXPERIMENT.md` after prompt 2.
- [ ] Show `experiments/001-first-example/outputs/metrics.json` with 9,000, 6,200, and 2,800 after the record.
- [ ] End on the audit result or the one-step recommendation, not on a terminal command.
- [ ] Record a scriptable terminal GIF with `vhs`, or record a video with QuickTime Player.
- [ ] Export GIF at 12–15 frames per second, or video at 1080p.
- [ ] Play the export once with sound off and confirm that every path is readable.
- [ ] Check that the final capture contains no private data before publishing it.
