# 用 10 分钟理解你的 AI

HonestLab 给 AI 一张整洁的工作台、明确的长期规则和一本项目笔记。它不会替你作出科学判断。它负责整理文件和证据，让你能据此判断。

## AI agent 到底是什么

AI agent 是能在你的电脑上读取文件、写入文件并运行命令的 AI 助手。Claude Code、Codex CLI 和 Cursor 都属于这一类。普通聊天网页只能处理你发给它的内容，而 agent 可以查看整个项目文件夹，并更新其中的记录。

你可以把 agent 看成坐在工作台前的研究助理。它能按照清单做事，也能整理证据。但它仍可能误解科学问题，所以假设和论文主张的改动必须由你确认。

## Context window 是 AI 的工作记忆

Context window 指 AI 在一次对话中能放进工作记忆的信息。可以把它想成一张面积有限的桌子。AI 能处理桌面上的材料；新材料越来越多时，较早或相关性较低的内容可能离开桌面。

混乱的项目会加重这个问题。如果五个脚本看起来都在做同一件事，AI 就只能猜哪个仍在使用。如果结果没有链接到数据和配置，AI 可能找到数字，却不知道它代表什么。HonestLab 为每类信息规定一个固定位置，减少这种猜测。

## `AGENTS.md` 和 `CLAUDE.md` 是长期工作规则

想象桌子上方贴着一张简短的工作规则。助理每次开始工作时都先读它。

[`AGENTS.md`](../AGENTS.md) 是 HonestLab 的共用规则。它告诉 AI 文件应放在哪里、实验应怎样记录、如何保存实际运行的代码，以及何时必须先征得你的同意。遵循 `AGENTS.md` 标准的 agent 都可以使用这些规则。

[`CLAUDE.md`](../CLAUDE.md) 是 Claude Code 的入口。它让 Claude Code 读取同一套共用规则，并列出可用 skills。

## Skills 是任务操作卡

Skill 是针对一类任务保存的操作说明。你可以把六个 skills 想成放在桌边的六张操作卡。你提出某项任务时，AI 取出对应的卡片执行。

- [`welcome`](../.claude/skills/welcome/SKILL.md) 进行简短访谈并填写项目背景。
- [`help`](../.claude/skills/help/SKILL.md) 解释工作区，并给出一个直接的下一步。
- [`experiment`](../.claude/skills/experiment/SKILL.md) 规划、运行、保存并记录一项科学测试。
- [`audit`](../.claude/skills/audit/SKILL.md) 检查论文主张、实验记录、图、旧结果、链接和文件位置。
- [`status`](../.claude/skills/status/SKILL.md) 在一屏内显示当前研究状态。
- [`tidy`](../.claude/skills/tidy/SKILL.md) 提出安全的文件移动方案，获得确认后保留并整理旧材料。

操作卡不能替代判断。它的作用是让重复的文件和记录工作保持一致。

## Hooks 是由事件触发的自动规则

Hook 是在指定事件发生时自动运行的规则。它像实验室中的定时器，到达指定步骤就响。例如，未来的 hook 可以在分析命令运行前检查实验记录是否存在，也可以在文件改动后检查 Markdown 链接是否仍然有效。

HonestLab 当前没有提供任何 hooks。现有 skills 和 `AGENTS.md` 会告诉 AI 应该怎样做，但不能从技术上阻止错误操作。因此，你仍需定期使用 audit 流程。

## Memory 文件是项目笔记本

[`memory/`](../memory/) 文件夹是项目的长期笔记本。一次对话结束后，这些内容仍留在项目中。

- `decisions.md` 记录你在何时作了什么决定，以及原因。
- `glossary.md` 按照本项目的含义记录重要术语。
- `preferences.md` 记录你希望 AI 怎样回复和工作。

有了这些文件，你不必在每次对话中重复背景。`preferences.md` 还可以带到下一个项目。你可以复制回复语言、详细程度和工作偏好，再修改其中与具体项目有关的内容。

## 保持 AI 上下文清晰的五个习惯

1. **一次对话只处理一个主题。** 当你从一项实验转到无关任务时，新开一次对话。
2. **回来时先查看状态。** 说“显示研究状态”，让 AI 重新读取研究问题、假设、最近实验、最新结论和下一步。
3. **每月运行一次 tidy。** 说“整理这个项目”。先检查 AI 提出的移动方案，确认无误后再批准。
4. **让文件保持短小、用途明确。** 一个文件只承担一个清楚的用途。可复用代码放在 `src/`，实验记录放在 `experiments/`。
5. **AI 显得混乱时，让它重新读取规则。** 说“重新阅读 `AGENTS.md`，先告诉我当前项目状态，不要做其他操作。”
